
## 部署 kafka 集群

- 阶段过程：pre阶段：初始化集群部署（交互的方式确认部署信息，生成每个节点的部署脚本）；deploy 阶段：拷贝部署脚本到节点（可以是手动，也可以安装脚本支持 scp 拷贝到指定节点）；启动服务：在指定节点上启动服务

- 版本选择：默认版本是 4.3.2（目前最新 release 版的上一个版本），也支持部署时生成配置时指定镜像版本

- 集群规模：3 节点

- 部署方式：使用 docker compose 部署

- 部署角色：controller 和 broker 拆分部署（有各自独立的部署脚本、可以运行在同一台 vm，也可以拆分部署，看把部署脚本如何方式）

- 资源规格：先按照单台机器是 8c32g 的方式分配 controller 和 broker 资源，需要考虑 os 的资源预留

- 部署配置：部署相关的环境变量保存到 .env

- 服务配置：服务本身的配置也挂载出来（你先生成部署方案，列出来 kafka 哪些关键的配置需要在 pre 阶段确认的）
